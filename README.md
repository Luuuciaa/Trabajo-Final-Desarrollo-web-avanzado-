# 💻 Proyecto Final - Programación e Historia

Este proyecto fue realizado como **trabajo final de HTML, CSS y JavaScript**.

El sitio presenta un recorrido por la **historia de la programación**, combinando contenido informativo con diferentes recursos visuales e interactivos.

## 🚀 Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript
* SVG
* MP4 y OGV para contenido multimedia

## 📚 Secciones del sitio

El proyecto está compuesto por tres páginas principales:

* 🏠 **Inicio:** presentación del proyecto y acceso a las diferentes secciones.
* 📖 **Historia:** recorrido por algunos de los acontecimientos y personajes más importantes de la historia de la programación.
* 🎮 **Jueguemos:** sección interactiva relacionada con los contenidos del sitio.

También incluye un **modo día/noche**, efectos visuales, animaciones y contenido multimedia.

## 🎨 Diseño e interacción

El diseño fue desarrollado utilizando HTML y CSS, incorporando:

* Tarjetas interactivas.
* Efectos `hover`.
* Animaciones.
* Sombras y efectos de brillo.
* Diseño adaptable.
* Modo día y noche.
* Botones e íconos personalizados.

## 🎥 Video

El proyecto incluye un reproductor de video personalizado desarrollado con JavaScript.

El reproductor permite:

* Reproducir el video.
* Pausar el video.
* Visualizar la duración.
* Mostrar el tiempo actual.
* Utilizar una barra de progreso.

## ⚙️ JavaScript

JavaScript se utilizó para agregar interactividad y controlar diferentes elementos del sitio, trabajando con:

* DOM.
* Eventos.
* Botones.
* Funciones.
* Manipulación de elementos HTML.
* Reproductor de video.
* Cambio de tema.
